Now we’re gonna explain how it works.
For this reason I make a quick overview
First, the machine does stuff based on the symbol it has read and the state it has in some registers inside.
The state is a variable, and at the beginning of the program it needs to have some initial value, say 000.
Then, the machine is ready to read the symbol from the tape.
After doing this it has already collected all the input information,
and in order to do anything based on it, it uses something we’ll call a truth table (instruction table).
The truth table has rows for each combination of state and symbol,
and each row contains a 7-bit instruction.
So it’s basically a source code of the machine.
Now based on the first 5 bits of the instruction,
the machine goes into a new state and prints a new symbol in place of the on it has read before.
Then it moves the tape left or right, depending on the bit 6 fo the insturction…
…and if bit 7 is high, it extis the program.
If the program continues, the cycle starts over again.
The symbol reader is connected to 2 of the registers.
(the remaining ones are for the state)
When the reading pin goes up, it sets the register;
when it goes down – it resets it
