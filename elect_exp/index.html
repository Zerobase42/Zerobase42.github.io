⚡ 전자기 유도 실험 : 코일 회전에 따른 유도 기전력 변화

코일 안쪽 중심에 자석을 두고, 코일을 자석 중심으로 회전시킵니다.
ε = 0
ε = −N·dΦ/dt. 자석은 코일 중심에 고정되어 있고 코일이 회전하면 코일을 지나는 자기선속이 Φ = Φ₀cos(ωt)로 변하므로 ε = N·Φ₀·ω·sin(ωt)가 됩니다(Φ₀ = B·V / 2a, 자석은 점 쌍극자로 계산, ω = 2π·rpm/60). 코일 그림의 도선 겹수는 감은 횟수 N에 비례합니다(N/20겹). 코일이 3바퀴 도는 동안 600개 지점을 동일한 시간 간격으로 측정하며, 실험을 반복하면 다른 색으로 누적되어 겹쳐 비교됩니다.
